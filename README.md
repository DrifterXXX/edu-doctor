# 教育博士备考中心 | Education Doctorate Exam Preparation Platform

中国教育博士考试在线备考平台，包含复习宝典、真题精练、考前背诵和音频资源。

An online preparation platform for China's Education Doctorate (Ed.D.) exam, featuring study guides, practice questions, pre-exam memorization, and audio resources.

---

## 功能 | Features

- **复习宝典 Study Guide** — 5 章完整复习材料 / 5 chapters of comprehensive review material
- **真题精练 Practice Questions** — 互动答题模块 / Interactive quiz module
- **考前背诵 Pre-exam Memorization** — 核心考点快速记忆 / Quick recall of key exam points
- **音频支持 Audio Support** — 各章节配套音频（46 个文件）/ Chapter-aligned audio (46 files)

## 快速启动 | Quick Start

```bash
cd edu-doctor/public
python3 -m http.server 8080
```

打开 Open `http://localhost:8080`

## 构建 | Build

使用 `exam-template` 工具从 JSON 数据生成。

Generated from JSON data using the `exam-template` tool.

## 技术栈 | Tech Stack

纯前端静态站点：HTML5 + CSS3 + JavaScript，JSON 数据驱动。

Static frontend site: HTML5 + CSS3 + JavaScript, driven by JSON data.
